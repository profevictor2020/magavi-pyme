# MAGAVI — Frontend

React + Vite + TypeScript. Ver documentación del proyecto en `../docs/` y
el estado general en `../README.md`.

## Desarrollo local

```
npm install
npm run dev
```

## Scripts

- `npm run dev` — servidor de desarrollo.
- `npm run build` — build de producción (`tsc -b && vite build`).
- `npm run lint` — lint con oxlint.
